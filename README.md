# Sistema de Chamados em Java

Projeto pessoal desenvolvido para praticar Java e lógica de programação.

O sistema permitirá registrar e acompanhar chamados de suporte.

## Funcionalidades planejadas

- Cadastrar chamado
- Informar título, descrição e prioridade
- Listar chamados cadastrados
- Alterar o status do chamado
- Consultar chamados por status

## Tecnologias

- Java
- Programação orientada a objetos
- Git e GitHub
